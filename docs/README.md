# Documentation Index

Project documentation belongs in this `docs/` folder (or in feature-local folders when tightly coupled to code).

## Policy

- Keep repository-level docs here.
- Keep root documentation limited to:
  - `README.md`
  - `LICENSE`

## Tutorials and planning docs

- `tutorial.md` — end-to-end scenarios and screenshots
- `tutorial-scenario-playbooks.md` — P1 executable scenario playbooks (prompt, tool path, done criteria, screenshots)
- `tutorial-troubleshooting.md` — known runtime issues and fixes
- `tutorial-model-configuration.md` — model/runtime configuration guidance
- `upstream-scenario-coverage.md` — upstream Magentic-UI scenario coverage matrix and backlog
