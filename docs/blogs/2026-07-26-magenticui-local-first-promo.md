## LinkedIn promo options

### Option 1
I published a new write-up on building a local-first Magentic UI experience in .NET.

The project ports Magentic-style agent orchestration to Blazor Server and uses ElBruno.LocalLLMs for local ONNX inference. It is orchestrated with Aspire, so you get operational benefits such as service wiring, distributed traces, and GenAI traces in the Aspire dashboard.

A key point from Microsoft Research that influenced this implementation: strong agentic capability comes from orchestration and action loops, not from model knowledge alone. That makes smaller, specialized models practical for real tasks.

- Aspire orchestration and end-to-end traceability

The architecture is inspired by the Microsoft Research MagenticLite direction and demonstrates how those ideas can be applied directly in C#.
